# gymweb

A simple static website for a gym / fitness business built with HTML, CSS, and JavaScript.

---

##  Overview

Gymweb is a front-end only project that showcases the branding, design, and user interface of a gym or fitness center. It includes:

- **Landing page** (`index.html`) with responsive layout  
- Styling via `style.css`  
- Interactive or dynamic front-end behavior using `script.js`  
- Images/assets stored in the `images/` folder  

This repo serves as a template / demo for a gym’s website presence (home page, features, gallery, contact sections etc.).

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (vanilla)  
- Responsive design for desktop and mobile viewports
